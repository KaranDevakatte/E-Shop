We have created E-Shop folder, abhi issi folder ke andar hum apna puraa project code store karenge.

Let's Begin!

sabse phele khud ka package.json file initialise kar lete hai, iske liye we will be using command
# npm init -y

uske baadh hum express package ko install karte hai, jo ki hum server setup karne mai help karengi
# npm install express or npm i express

hum ejs templates ka use karenge, it helps to create a view or display jaha pe user can interact
with our website
# npm install ejs or npm i ejs

now lets create a file (app.js), jaha pe hum apna server setup karenge and apis banayenge
we can use following command to create a file from terminal
# touch app.js
